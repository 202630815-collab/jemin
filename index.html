GitHub Pages 무료 배포 가이드

이 코드를 내 깃허브(GitHub) 저장소에 올려 누구나 방문할 수 있는 웹사이트 URL로 만드는 방법입니다.

STEP 1. GitHub 저장소(Repository) 생성

1) GitHub.com 로그인 후 우측 상단 [+] -> [New repository] 클릭
2) Repository name에 username.github.io 형식 또는 원하는 이름(예: mind-rest) 입력
3) Public 선택 후 [Create repository] 클릭

STEP 2. index.html 파일 저장 및 업로드

1) 현재 웹페이지의 전체 소스코드를 복사하여 컴퓨터에 index.html 이름으로 저장합니다.
2) 생성된 GitHub 저장소 화면에서 "uploading an existing file" 링크를 클릭하고 index.html 파일을 드래그하여 올립니다.
3) 하단 [Commit changes] 버튼을 누릅니다.

STEP 3. GitHub Pages 활성화

1) 저장소 상단 메뉴에서 [Settings] -> [Pages] 선택
2) Build and deployment 의 Branch 항목에서 main (또는 master)을 선택하고 [Save] 클릭
3) 1~2분 후 저장소 상단에 표시되는 내 전용 URL(https://username.github.io/mind-rest/)로 접속합니다!
